# 🌐 TechWorld

✨ Projeto desenvolvido com foco em tecnologia, inovação e tendências digitais.

## 💻 Sobre o projeto
O TechWorld é um site criado para compartilhar informações sobre o mundo da tecnologia, incluindo novidades, inteligência artificial, programação, dispositivos eletrônicos e inovações digitais.

## 🚀 Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## 📱 Objetivo
Apresentar conteúdos modernos sobre tecnologia de forma criativa, organizada e acessível para todos.

## 🌎 Tema
Tecnologia, inovação e futuro digital.
